# 聊天控件与抽屉交互实现规范

日期：2026-10-31

状态：已实现；自动化和核心真机场景通过，剩余组合交互待复测。

## 行内文件识别

- Markdown 解析器保留显式链接语义。
- 对带反引号的 run 额外识别高置信文件引用：无空白、带路径分隔符或文件扩展名，
  或使用支持的 URI scheme；普通命令、变量名和表达式不自动变为链接。
- 识别出的引用写入 `href`，视觉使用当前主题的链接色，不改变可见文本和复制语义。
- 文件解析继续由 `NativeLinkResolver` 完成；目录先 stat 失败后进入文件浏览器。

## 更多菜单

- 菜单在点击的同一帧使用完整的两项列表，不从“正在加载”占位开始。
- 会话选择后后台预取 capabilities，并按 session ID 缓存；菜单首帧使用缓存或乐观
  完整列表。
- capabilities 不支持导出时，在已知后禁用相应项；请求失败不得卡住菜单或清空项。
- 菜单弹出只使用位置与透明度，不等待网络请求。

## 折叠状态

- 每个可展开单元使用由 `turnKey + message id + section` 构成的稳定 key。
- Map 只表示“用户已展开”，不能把“当前某项展开”实现成单值 ID。
- 工具调用、思考过程、边界和 footer 必须绑定到同一 turn，但各自保持独立可展开
  状态；父 turn 展开不能伪造子项状态。
- 过程组不再创建内部有界滚动画布；展开后的成员直接进入外层聊天列表，由同一
  滚动所有者呈现，避免“只看到一个，再点像跳到下一个”的嵌套滚动错觉。
- 增量消息替换时保留已有 key 的展开状态；删除或切换到另一会话时清理不再存在的
  临时状态。

## 设置动效

- 主题选择、布尔开关、通知级别和 Host select 使用 `NativeMotion.animate(..., 'micro')`。
- 网络保存失败时，界面只在 Host 确认回退动作中恢复到权威值。
- 系统或 App 的减少动态效果开启时直接更新最终状态。

## SVG 主题

- SVG 统一使用 `Image.fillColor`，不使用颜色矩阵作为主着色路径。
- 主题变化时 Image 身份包含 `light/dark`，避免解码缓存复用上一主题的像素。
- 若单个资源含不可着色描边，应修复资源本身；不得用背景色块遮挡黑边。

## 抽屉动画

- 抽屉和遮罩始终挂载；关闭状态通过水平位移和 opacity 隐藏，避免条件卸载造成
  无法插值的首尾帧。
- 打开、关闭、拖动释放都在 `surface` 语义时长内更新同一组 translation/opacity。
- 关闭完成后禁用命中测试；打开或在拖时恢复命中测试。
- 背景和命中层从窗口顶部绘制以保持材质连续；手机侧栏内的标题、搜索、列表和
  底部操作统一从 `safeTop` 开始，避免文字与状态栏图标重叠。
