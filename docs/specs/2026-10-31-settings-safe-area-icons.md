# 设置层级、安全区与主题图标实现规范

日期：2026-10-31

状态：已实现；本地契约验证与核心真机场景通过，完整跨窗口矩阵待复测。

## 现状与根因

- `NativeSettings` 的根页和二级页外层仅有约 `4vp` 左右内边距，因此标题视觉上
  贴近屏幕边缘。
- 二级页 `Scroll` 没有显式顶部起点；宽屏 `maxWidth` 内容容器在部分 ArkUI
  布局组合中采用了不符合页面层级的垂直对齐。
- 设置保存成功、错误和重试信息由页面组件共用，切换页面时没有清理。
- Host 设置状态保存在类对象中，选择器显示依赖对象成员更新；在当前 ArkUI
  重绘粒度下，不能稳定触发选择器重新取值。
- 首页抽屉内容自身有安全区 padding，但抽屉背景、遮罩和边缘手势从窗口顶部
  开始，仍可能在状态栏区域产生视觉或触摸侵入。
- SVG 资源同时包含 fill 和 stroke。仅依赖颜色矩阵时，部分描边路径会在主题
  切换后保留原黑色像素。

## 页面框架

### 统一设置框架

- 根页和所有二级页使用相同的屏幕级左右边距：基础 `12vp`，再叠加窗口左右安全区。
- `pageHeader` 在屏幕级边距内再保留 `4vp`，使返回箭头与内容卡片内部的文字网格
  对齐；根页“设置”标题与返回控件使用同一顶部基线。
- 页面内容使用 `16vp` 左右内边距和 `0` 顶部内边距，并限制最大宽度。
- 所有 `Scroll` 显式采用顶部起点对齐。宽屏下限制内容宽度，不改变内部左对齐。
- 关于页作为二级页使用时共享同一页面标题框架，内部只保留组件内容边距。

### 状态隔离

- `openPage` 在页面切换前清除通用的 `status`、`error`、Host 错误和重试参数。
- 操作结果仍保留在当前页面，直到离开该页。
- 测试通知成功并实际提交后，将当前会话的通知权限状态显式更新为已开启；后续
  进入前台时仍以系统权限 API 的结果为准。

### Host 设置回显

- `NativeChatPreferences` 继续是规范化后的唯一投影。
- `NativeSettings` 增加原始类型状态字段，用于驱动 ArkUI 选择器；每次 Host revision
  变化或写入完成后都从 `hostSettings.chat()` 重新赋值。
- 写入失败时以 Host 重新读取的值为准，不保留假成功。
- 单元测试覆盖 `compact`、`standard`、`detailed`、`verbose`、收起时机、折叠回复
  和运行时发送的投影。

## 图标与品牌资源

- 从固定上游版本复制 DeepSeek favicon SVG 到
  `resources/rawfile/dsh-icons/deepseek-logo.svg`，保留品牌路径和 `viewBox`。
- `DSHIcon` 将 `deepseek-logo` 纳入随包 SVG 分支。
- SVG 使用 ArkUI 的增强 SVG 解析，并通过 `SRC_IN` 混合过滤器对整幅已栅格化
  图像着色。该路径同时覆盖 `fill` 与 `stroke`，并保留原图透明度；仅使用
  `fillColor` 会留下显式描边的原始黑色像素。
- 主题切换时颜色必须由当前 `nativeDark` 与调用方语义色重新投影，避免 Image
  解码缓存保留上一主题像素。
- 若真机仍出现描边黑边，改用随包浅色/深色变体资源；不通过网络加载图标。
- 图标颜色继续使用 DSH 的中性、弱化和品牌色语义 token，不新增装饰性渐变。

## 关于页作者入口

- `BuildInfo` 增加 `authorProfile`，值固定为项目维护者的 GitHub 主页。
- 关于页作者卡显示头像、用户名和主页文本；整卡可点击，使用系统 `viewData`
  Ability 打开链接。
- 作者主页、项目仓库和 Issues 继续使用同一打开失败提示，不暴露私有地址。

## 安全区与抽屉

- 手机抽屉面、遮罩和左侧边缘手势从窗口顶部连续绘制，不额外制造横向或顶部
  空白。
- 抽屉内的标题、搜索、会话列表和设置 footer 从 `safeTop` 开始；背景材质可
  延伸到状态栏下方，但文字和可交互控件不得与其重叠。
- 主聊天内容继续显示系统状态栏，并使用已有 `safeTop`/`safeBottom`。
- 底部系统手势区保持页面背景连续；交互控件不进入安全区。
