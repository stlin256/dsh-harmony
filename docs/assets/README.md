# README assets

These files are used only by the repository landing pages.

| Asset | Intended render size |
| --- | --- |
| `dsh-harmony.svg` | 96×96 px |
| `deepseek.svg` | 22×22 px |
| `huawei-appgallery.svg` | 34×34 px |

Use explicit `width` and `height` attributes in Markdown HTML so the artwork
does not expand beyond the product introduction. Keep the originals intact.

The DSH Harmony mark is the app icon. The DeepSeek mark comes from Simple Icons
(CC0). The Huawei AppGallery icon is the public-domain
[Huawei AppGallery.svg](https://commons.wikimedia.org/wiki/File:Huawei_AppGallery.svg)
published on Wikimedia Commons.
