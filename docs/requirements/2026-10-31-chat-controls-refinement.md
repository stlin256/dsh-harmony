# DSH Harmony 聊天控件与抽屉交互收口需求

日期：2026-10-31

状态：真机反馈已确认，待实现。

## 目标

消除聊天消息、顶部操作菜单和手机抽屉中的等待、错位与状态错配，并统一主题图标
和设置控件的即时反馈。

## 功能要求

- `CHAT-FILE-01` 行内代码中明确指向文件、目录或带行列锚点的路径应可点击，并按
  当前会话工作目录解析为目标文件或目录。
- `CHAT-FILE-02` Markdown 链接、相对路径、`file://`、`dsh-resource://`、图片和
  目录继续使用已有预览、文件浏览器或外部打开路径。
- `CHAT-MENU-01` 聊天右上角更多菜单点击后应立即显示“复制 Markdown”和“下载日志”
  两项，不得先出现“正在加载…”。
- `CHAT-FOLD-01` 思考、工具调用与折叠回合必须拥有稳定身份；展开一段不得收起或
  跳到另一段。
- `CHAT-SETTINGS-01` 设置中的主题、开关、分级选项和 Host 选择器在状态变化时使用
  统一语义动效，并支持减少动态效果。

## 视觉与主题

- `THEME-01` 侧边栏和设置内的 SVG 在浅色、深色切换后不得残留上一主题的黑色或
  白色像素。
- `THEME-02` 未选中图标、选中图标和禁用图标必须保持可辨识的层级。

## 抽屉

- `DRAWER-01` 手机抽屉打开和关闭均使用明确的进入/退出动画，不出现无过渡闪现。
- `DRAWER-02` 抽屉背景可从窗口顶部开始绘制，但标题、搜索、会话列表和底部操作
  必须限制在系统安全区内，不得与状态栏图标形成不可读重叠。
- `DRAWER-03` 左缘手势、横向拖动、遮罩点击、关闭按钮和系统 Back 使用同一状态。

## 验证

- 自动化覆盖行内文件路径识别、Host 设置投影和折叠状态纯函数。
- 真机覆盖浅色/深色图标、聊天文件、更多菜单首帧、设置选项反馈、折叠连续展开、
  抽屉打开/关闭和状态栏边界。
