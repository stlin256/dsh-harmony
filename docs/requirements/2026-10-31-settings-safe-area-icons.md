# DSH Harmony 设置层级、安全区与主题图标修复需求

日期：2026-10-31

状态：已实现；核心设置页与图标场景已真机验收，剩余跨窗口场景待复测。

## 目标

统一设置根页和全部二级页的视觉框架，修复首页抽屉侵入系统状态栏的问题，
并让设置图标、DeepSeek 品牌标识和关于页作者入口在浅色与深色主题下保持一致。

## 功能与视觉要求

- `SETTINGS-01` 所有设置二级页的标题、返回控件和内容从页面顶部开始，不得因
  `Scroll` 默认对齐或窄内容容器而垂直居中。
- `SETTINGS-02` 设置根页与全部二级页共用同一左右边距；“设置”标题和二级页返回
  箭头不得贴近屏幕边缘。平板和宽屏下内容保持居中，但内部文字仍左对齐。
- `SETTINGS-03` 二级页切换时不得显示上一页的保存状态、错误或重试信息；设置项
  的异步结果只能出现在发起操作的页面。
- `SETTINGS-04` Host 设置写入成功后，选择器应立即显示服务端确认值；重新进入设置
  仍应保持同一值。
- `SETTINGS-05` “DSH 设置”使用随包分发的 DeepSeek 官方 SVG 标识，不依赖网络
  资源，也不使用占位齿轮代替。
- `SETTINGS-06` 所有设置内 SVG 图标在深色模式下不得残留黑边或黑色填充，并保持
  清晰的浅色/深色语义色。
- `SETTINGS-07` 关于页作者名称下方显示并可点击打开作者 GitHub 主页；不得继续
  显示无链接的“GitHub 作者”占位文本。

## 安全区要求

- `SAFE-01` 抽屉面、遮罩和左缘手势可以从窗口顶部连续绘制；标题、搜索、列表、
  设置 footer 等内容必须限制在系统状态栏以下的可用区域。
- `SAFE-02` 抽屉打开和拖动时，文字、图标和可交互控件不得与状态栏图标重叠。
- `SAFE-03` 底部系统手势区继续保持页面材质延伸，同时交互内容避让安全区。
- `SAFE-04` 左右安全区、窄屏、横屏和分屏下不得产生新的横向溢出。

## 验收要求

- 浅色和深色主题分别检查设置根页、DSH 设置、外观与动效、通知、桌面卡片、
  服务与账户和关于页。
- 用真实设备检查系统 Back、页面返回、抽屉左右滑动、状态栏边界和作者主页跳转。
- 自动化测试覆盖 DSH 设置值投影和页面状态隔离；真机截图证据不得进入公开仓库。
