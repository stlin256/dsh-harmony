# DSH Harmony 用户要求与问题登记

日期：2026-10-30。本文是本轮研究、spec、实现和验收的需求清单。用户要求先完整记录，再分类研究和写spec，之后才继续实现。已有未提交补丁不等于验收通过；本轮先暂停新增App实现。

## 1. 用户最近反馈原文

### 1.1 主题、加载与内容

> 你现在有问题，切换暗色模式后很多文本和控件没有转换颜色
> 其次是打开聊天总是需要加载很久，内容加载成功之前一直都是显示连接中断，正在尝试重连
> 以及对话图片无法预览显示、markdown格式表格无法渲染，文件都不能预览只能复制链接等

### 1.2 过程密度与设置

> 而且你折叠的思考过程，明明刚刚好思考过程右边还有空间可以显示最开始的一行字，你也没显示，以及思考过程和工具调用之间空隙还能压缩下
> 设置界面三个TAB割裂：点击关于的时候变成单独页面
> 以及设置中很多选项点击后没有反应，开启的开关还是开启的等问题

### 1.3 列表、工作区、性能与执行方式

> 通用设置打开会等一下才出选项，以及工作区没有区分
> 从聊天退出之后列表里面刚才的聊天还是高亮
> 主页聊天列表点击三个点后三个点的区域应当高亮才能看出你点的是哪个聊天的三个点
> 聊天标题有字数限制，没有显示全，出现截断
> 这些问题你都得修复啊
> 以及工作区里面显示工作区接口暂不可用
> 以及反复出现连接中断，正在尝试重新连接，你能不能让加载速度等的优化好提起来啊？
> 你把我这段话和上面提出的要求，全部落盘到文件，然后再对着要求一条一条研究和写spec，然后才开始写代码
> 你应当分类派出子代理来研究怎么做

### 1.4 上游与服务版本

> 你先派出子代理，clone deepseekharness的源码，看看他的交互界面的完整设计逻辑，
> 然后你来把这些交互，原汁原味的交互逻辑用鸿蒙的代码写一遍，做手机端适配，
> 写好spec再开干

## 2. 逐项需求与验收意图

### THEME：主题与系统区域

| ID | 用户要求 | 必须验证 |
| --- | --- | --- |
| THEME-01 | 亮/暗/跟随系统完整切换 | 文本、输入/占位、按钮、Select弹层、Switch、菜单、读图/文件页、加载/错误状态同时一致 |
| THEME-02 | 不能只切背景 | ArkUI默认控件的主题作用域与显式DSH语义色均覆盖；浅色和深色间反复切换，无黑字落暗底或白字落浅底 |
| THEME-03 | 保留状态栏，取消全屏设置 | 内容避让顶部；设置不出现全屏选项 |
| THEME-04 | 底部小白条区域沉浸 | 手势区与所在页面同色；输入区避让键盘与安全区，不能靠额外固定空白实现 |
| THEME-05 | 鸿蒙特性与动效 | 遵从系统及App减少动效/透明设置；不为每次token刷新重复播放动画 |

### CONNECT：连接、首屏与缓存

| ID | 用户要求 | 必须验证 |
| --- | --- | --- |
| CONNECT-01 | 首次加载不能冒充断线 | loading与连接失败/重连为不同状态；只有真实失败才显示短横幅 |
| CONNECT-02 | 缩短打开聊天时间 | 分别测缓存首帧、冷打开首帧、权威快照完成；检查重复HTTP/WS读取、初始窗口与同步投影成本 |
| CONNECT-03 | 反复连接中断必须定位根因 | 核对官方Mux、现代control、认证、Origin端口、generation、超时、seq/revision缺口与错误帧；不能只隐藏横幅 |
| CONNECT-04 | 缓存维护和恢复 | 切会话、设置、兼容面板、前后台和重连保留已有记录/草稿/附件/阅读位置；退出清理对应身份的数据 |
| CONNECT-05 | 不自动重发消息 | 超时/断线按requestId对账，不使用新ID重复提交；显示简短未确认状态 |
| CONNECT-06 | 通用设置立即有可用内容 | 从最后成功的Host镜像立即渲染，后台刷新；不得每次打开都先空白再补选项；写入仍用最新revision |
| CONNECT-07 | 状态文案简短 | 断线统一横幅“连接中断，正在尝试重连”；不插入大段说明或每条重复错误 |

### WORKSPACE：工作区与聊天列表

| ID | 用户要求 | 必须验证 |
| --- | --- | --- |
| WORKSPACE-01 | 工作区明确区分 | 使用真实Host实体和membership分组/选择，不能只把全部会话平铺为一个工作区 |
| WORKSPACE-02 | 工作区功能完善 | 目录选择、添加、重命名、移除注册、排序、会话归属、归档/恢复/置顶和错误恢复；不删除远端目录 |
| WORKSPACE-03 | 修复“工作区接口暂不可用” | 对比真实Host API与手机链路；保留最后好快照，分类错误并能重试，不能吞掉异常后永久停在空态 |
| WORKSPACE-04 | 退出聊天后取消列表高亮 | 手机退出主会话视图时不残留“正在打开”的选中样式；缓存与最近访问身份可保留但不能冒充当前选择 |
| WORKSPACE-05 | 三点区域有明确高亮 | 菜单打开期间对应会话行/三点触发区可识别；关闭/切目标后复位，不高亮另一行 |
| WORKSPACE-06 | 标题完整 | 会话顶栏、列表及菜单中不人为裁切字符串；长标题有可阅读的完整排版，不能静默省略为不可见内容 |
| WORKSPACE-07 | 隐藏空对话 | 依据blank与真实内容，过滤其他空会话、系统注入和顶级子代理；新建/复用不堆空条目 |
| WORKSPACE-08 | 会话菜单精致且遵循官方语义 | 侧栏管理、标题utilities和更多视图区分；锚定浮层，不把所有操作堆成粗糙整页；顺序、图标、忙碌/禁用/错误有依据 |
| WORKSPACE-09 | 搜索与列表紧凑 | 可搜索名称/ID/工作区/内容，按官方排序和去重；长标题、多状态、大字体仍可触达 |

### RENDER：聊天、图片、Markdown与文件

| ID | 用户要求 | 必须验证 |
| --- | --- | --- |
| RENDER-01 | 图像可以显示与预览 | 持久附件与Markdown图片经授权读取，自动缩略图、加载/重试、原图预览、关闭/系统返回；不只是“查看图片”按钮 |
| RENDER-02 | Markdown表格正常渲染 | GFM表头/分隔行/对齐、转义pipe、行内代码/链接、不同列数、宽表局部横滚；复制保留原文 |
| RENDER-03 | 文件可预览而非只复制链接 | DSH resource、绝对/相对路径、行号、Markdown关联文件均路由到正确远端文件；文本/代码/Markdown/图片及系统支持的PDF/Office等有实际预览 |
| RENDER-04 | 预览保持认证与文件语义 | 使用公开Host文件API的真实scope和二进制协议；文件版本变化不混页；错误可重试，返回保留聊天上下文 |
| RENDER-05 | 官方聊天格式与图标 | 人类/Assistant、块顺序、代码/引用/附件、运行状态和操作按上游交互；保持紧凑，不用JSON/占位页替代专用UI |
| RENDER-06 | 过滤系统注入 | 隐藏普通系统上下文，但保留原始journal供轨迹/诊断；真人输入、有效通知唤醒与问题回答不能误删 |
| RENDER-07 | 过程与工具呈现等同官方 | 同轮分组、Step、call/result/PTC、preparing、失败/停止、工具专用card model、四档偏好及折叠资格逐项核对 |
| RENDER-08 | 思考首行利用右侧空间 | 收起状态在标题旁显示规范允许的首行预览；实际宽度参与布局，不能被intrinsic button宽度挤掉 |
| RENDER-09 | 思考/工具间距进一步紧凑 | 排除重复padding、空节点和多层gap；保留可读层级及可触达区域 |
| RENDER-10 | 滚动与长记录 | 读旧内容不抢尾，补页/图片撑高/折叠后锚点稳定；完整内容可阅读，不用永久截断替代虚拟化 |

### SETTINGS：设置导航与真实行为

| ID | 用户要求 | 必须验证 |
| --- | --- | --- |
| SETTINGS-01 | 设置始终可打开 | 原生与兼容入口一致，背景会话常驻；没有无反应的cover或点击穿透 |
| SETTINGS-02 | 通用/应用/关于三个TAB连贯 | 三个TAB保留同一header与导航；关于内容在第三个TAB中，不能突然变为独立页面 |
| SETTINGS-03 | 二级页与系统返回 | 当前详情→设置父级→关闭设置，不一键退到设置外；旋转/窗口变化不覆盖返回能力 |
| SETTINGS-04 | 每个设置可用且状态真实 | 核对控件→Bridge/Remote→持久化→回读；错误回退、短提示、忙碌可见；无只改本地视觉的开关 |
| SETTINGS-05 | 通知分级 | 需要确认/失败/完成分别配置，插件和App执行一致；启用/停用系统推送真实注册/撤销，不能关闭后仍显示开启 |
| SETTINGS-06 | Push与无Push区别 | 本地自编译Push版接插件服务凭据；无Push可选后台监控；通知点击冷/热启动进入正确会话；暂不新增商店版本开发 |
| SETTINGS-07 | Host设置同步 | describe镜像、mutate revision、冲突恢复；显示模式/收起时机/回复策略实际驱动聊天，默认值不擅自写回 |
| SETTINGS-08 | 关于完整且素材本地 | App logo、项目名、版本、版权/许可、作者GitHub头像/用户名、仓库和Issues链接；素材打包，不依赖临时远程头像加载 |
| SETTINGS-09 | DSH风格、紧凑布局 | 官方菜单/设置分类/主题/图标语义，手机适配；不堆大段说明，不暴露实现细节给产品使用者 |
